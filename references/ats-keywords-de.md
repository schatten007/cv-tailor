# German ATS Keyword Mapping

Use this reference when the advertisement is in German or the employer's ATS is
likely configured for German. The goal is faithful terminology, not keyword
stuffing.

## Extraction Order

1. Must-have qualifications, licenses, degree names, and language levels.
2. Repeated job titles, tools, systems, methods, and domain terms.
3. Explicit responsibilities and scope signals.
4. Named soft skills, only when the candidate can prove them.
5. Nice-to-have requirements, only when supported.

Put high-priority terms in the profile, relevant experience bullets, and plain
text skills section. A term without evidence belongs in the gap analysis, not in
the resume.

## Standard Heading Pairs

Use the language of the advertisement consistently. These are useful mappings,
not interchangeable instructions:

| English | German |
| --- | --- |
| Professional Summary | Kurzprofil / Profil |
| Work Experience | Berufserfahrung / Beruflicher Werdegang |
| Practical Experience | Praktische Erfahrung |
| Education | Ausbildung / Studium / Bildungsweg |
| Skills | Kenntnisse / Fachkenntnisse / IT-Kenntnisse |
| Languages | Sprachen / Sprachkenntnisse |
| Certifications | Zertifikate / Weiterbildungen |
| Projects | Projekte |
| Volunteer Experience | Ehrenamt / Engagement |
| Publications | Publikationen |

Do not replace a standard heading with creative labels such as `Mein Weg`,
`Was ich kann`, or `Toolkit` when ATS parsing matters.

## Term Matching Rules

- Copy the exact, truthful term from the advertisement at least once.
- Preserve the official tool, framework, certification, and job title spelling.
- Add an established acronym and full form where useful: `Customer Relationship
  Management (CRM)`, `Key Performance Indicators (KPIs)`, `SQL (Structured Query
  Language)`.
- If the ad uses an English term inside German text (`Software Engineer`, `Scrum
  Master`, `Account Manager`), retain it and do not force an awkward translation.
- If the candidate's official title differs from the ad's title, keep the real
  title and add a truthful clarifier, for example `Mitarbeiterin Kundenservice
  (Customer Service Specialist)`.
- Do not claim a German regulated qualification, official equivalence, visa,
  language level, certification, or tool version without evidence.
- Truthful synonyms and related terms are fine; many matchers map related terms
  to the same skill. Use them naturally in context rather than as a keyword
  list, and do not force an awkward exact copy of the ad's wording.

## Common Keyword Families

| Job-ad signal | Possible evidence locations |
| --- | --- |
| `Projektmanagement`, `Projektleitung` | Profile, role bullets, project scope, PMP/PRINCE2 certificate |
| `Stakeholder-Management`, `Schnittstellenmanagement` | Cross-functional bullet with named groups and outcome |
| `Prozessoptimierung`, `Continuous Improvement` | Before/after metric, Lean/Six Sigma method, system change |
| `Datenanalyse`, `Reporting`, `Business Intelligence` | Tool, dataset/scale, dashboard or decision impact |
| `SQL`, `Python`, `Power BI`, `Tableau` | Skills plus an experience bullet showing actual use |
| `SAP`, `SAP S/4HANA`, `FI/CO`, `SuccessFactors` | Exact module and role context; never infer module knowledge |
| `Agile Methoden`, `Scrum`, `Kanban` | Team/process context and delivered outcome |
| `Kundenbetreuung`, `Customer Service` | Customer volume, channel, SLA, satisfaction, or resolution metric |
| `Qualitätsmanagement`, `ISO 9001` | Standard, audit, corrective action, measurable result |
| `Deutsch B2/C1`, `Englisch C1` | `Sprachen` section and only verified language evidence |

## Placement Pattern

Weak:

```text
SQL, Python, Agile, communication, leadership, stakeholder management
```

Stronger:

```text
Data Analyst with 4 years of Python and SQL experience; built Power BI reporting
for 12 business units and presented KPI findings to Finance and Operations.
```

The second version gives the ATS the terms and gives the recruiter evidence.

## Final Keyword Check

- Every must-have term is present, absent with an explicit gap, or represented by
  a truthful equivalent with an explanation.
- German/English terminology is not mixed randomly.
- Keywords appear in context in the profile, experience, or skills sections.
- No hidden text, white text, duplicate keyword blocks, or keyword stuffing.
- Acronyms and full terms are paired where the target system may use either.
- The exact job title is used only when it accurately describes the candidate.
